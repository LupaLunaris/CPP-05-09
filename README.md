# C++ modules 05–09

A continuation of my C++ exercises from the 42 curriculum.

The repository is split into modules `05/` through `09/`. The exercises cover exception handling and more advanced use of C++ facilities, templates and containers.

## Build

Each exercise is standalone; enter its directory and use the provided Makefile when available.

```bash
cd 05/ex00
make
```

The exact executable depends on the exercise.

## Purpose

I keep these modules as part of my 42 learning record. They show a progression through C++ concepts rather than one unified application.
